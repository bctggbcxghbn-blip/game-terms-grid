# ゲーム用語マス表

index.htmlをChrome・Edgeで開いて使います。外部ライブラリや通信は不要です。

- 動画版は削除し、空白から編集する表に統一しました。
- マスを選択しても問題文の入力欄は非表示です。「問題文を編集」を押したときだけ開きます。別のマスを選んでも開閉状態を保ちます。
- 白：赤文字で「知ってる」。黄色：入力した問題文。灰色：常に文字を非表示。
- 「まとめて黄色にする」で白いマスとゴールを除く全マスを黄色にします。
- 色や表示を変えても入力した問題文は保持されます。PNGにも表示状態を反映します。
- 取り消し・やり直し、コピー・貼り付け、JSON保存・読込、PNG保存に対応します。
- 編集内容はブラウザに自動保存します。大切なデータはJSONでも保存してください。
- 旧バージョンの保存・JSONは空白版の編集データを引き継ぎます。旧動画版のデータは読み込みません。
- 12行×18列とゴール6個。行列の追加削除、検索、全画面は未実装です。

「まとめて灰色にする」で白い「知ってる」とゴールを残し、ほかのマスを灰色にして問題文を隠します。入力内容は保持され、取り消しや黄色への一括変更で戻せます。編集欄も閉じます。

## スマホでの操作

表は上下左右にスワイプできます。マスをタップして選び、表の下にある色ボタンで変更します。問題文は「問題文を編集」を押したときだけ表示されます。ボタンは指で押しやすい大きさです。初期表示は「全体を表示」で表全体を横幅に合わせます。表示倍率を変更すると拡大してスワイプできます。編集欄は表の下にあり、画面には固定されません。
